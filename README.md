# Nemi · 妮米

**能理解目标、使用工具并持续推进工作的个人 Agent。**

面向国内个人用户的通用助理，对标 Meta Muse 与 OpenAI dots 的持续执行、应用连接、记忆和云端电脑体验，覆盖生活、工作、学习与研究。采用 **Next.js + Go + Eino + Temporal + PostgreSQL**；事项与提醒是可调用能力，云端浏览器尚待交付。

## v0.8 已交付

- 对话内上传 PDF / Word / Excel / CSV / 文字资料、读取公开 HTTPS 网页；精确表格统计和报告 / Excel 成果的内部预览、下载、刷新恢复。范围与限制见 [资料与成果](docs/FILES.md)。

- 首页直接与 LLM 对话：消息发送、多轮上下文、历史切换、刷新恢复、后台执行与错误显示；对话不会自动创建事项。
- Eino 有界工具循环：查询个人事项与偏好、读取北京时间、应用状态和指定飞书文档；工具结果回传模型继续处理。
- 会话 harness：持久化历史摘要与任务计划、重复工具调用保护、停止当前执行；摘要使用所选真实模型并计入预算。
- 自然语言连接应用：在对话卡片配置飞书文档及三平台群机器人，连接后继续原任务；凭据不进入模型上下文。
- Agent 准备群消息，用户在对话内核对接收群与正文后确认发送；配置变更阻止旧提案，未知回执不自动重发。
- 执行过程与操作提案：对话中查看具体内容与时间，确认后真实创建事项 / 站内提醒；重复确认只执行一次，取消和过期提案不执行。
- 中文响应式首页、事项清单、工作动态、生活偏好与应用目录；首页直接配置个人模型，首个配置自动设为默认。
- 通义千问、DeepSeek、Kimi、豆包、智谱：保存个人密钥、选择默认模型或任务模型、撤销配置、确认后真实调用检查。具体型号需有账号权限并通过检查。
- 凭据使用 AES-256-GCM 加密，绑定空间、用途与配置。密钥不回显，不写入任务参数、业务事件或 Git。
- 飞书、企业微信、钉钉群机器人：页面配置、签名、正文与目标预览、确认发送、持久去重和联调回执。
- 飞书官方 Go SDK：自建应用认证、读取选定且授权的 docx 文档、导入事项资料并保留原文入口。
- 高德官方地点搜索跳转、单次 ICS 日历导出、Markdown 清单下载。
- 事项持续补充资料与版本保护、已确认偏好引用、后台清单生成、费用预留与结算。
- Temporal 持久运行、PG Outbox、共享 SSE；一次性和有结束日期的周期站内提醒、北京时间与免打扰。

每次对话和清单生成都调用配置的真实模型。未配置有效 Key 时明确阻止执行，不提供模拟答案。保存配置不会自动调用模型、读取文档或发送消息。真实账号授权与实群验收记录见 [实施状态](docs/IMPLEMENTATION.md)。

## 本地运行

Windows 请使用 Git Bash。完整步骤见 [开发运行指南](docs/DEVELOPMENT.md)。

```bash
cp .env.example .env
# 修改邀请口令后启动基础设施与后端：
docker compose up -d --build
cd apps/web
npm ci
npm run dev
```

访问 http://localhost:3000。API 与 Worker 必须共享加密主密钥；Compose 挂载同一 credential-data 卷。无 Docker 时可使用仓库的 PostgreSQL 与 Temporal 开发脚本。

登录后打开首页右上角「模型配置」，填写服务商、模型 ID、API Key 和该型号每百万 Token 单价，保存后即可发送消息。首页 Enter 发送、Shift + Enter 换行。长对话整理为摘要加近期原文，完整记录保留；切换模型时，这些背景和工具读取的资料会发送给新选定服务商。摘要可能遗漏细节，关键要求可再次明确。

可以直接说「帮我连接企业微信」「总结这份飞书文档」「把工作安排发到已连接的飞书群」。首次平台开通和文档授权仍需你或管理员完成；妮米提供内部配置卡片，不能凭空获得账号权限。所有群消息先展示提案，不会因为一句话直接发送。

## 验证

所有集成测试使用专用 nemi_test 数据库及独立 Temporal 队列，不能对用户数据库执行清理。先按运行指南配置 TEST_DATABASE_URL 和 TEST_TEMPORAL_ADDRESS，再执行：

```bash
source scripts/env.sh
go test -count=1 ./...
go vet ./...
bash scripts/build.sh
npm run test:e2e:isolated
cd apps/web
npm run build
npm run typecheck
```
