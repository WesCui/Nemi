# Nemi Web 视觉与交互

对应 v0.3。中文个人生活助理，采用安静、清楚的工作台风格，页面主角是用户事项及时间。

## 视觉基线

| 属性 | 实现 |
| --- | --- |
| 基底 | 纸白 `#f6f5f1`，内容纸面 `#fffefa` |
| 文字 | 炭黑 `#292d29`，次级灰 `#72766f` |
| 强调 | 深绿 `#35564b`，主操作 `#254237` |
| 分隔 | `#e2e3dc` 的细线；避免大量有色容器 |
| 布局 | 固定窄侧栏，内容居中；首页概要、输入、事项、提醒层次分明 |
| 形状 | 控件圆角 5–6px，内容 8px，弹窗 10px；不使用漂浮胶囊墙 |
| 字体 | 系统中文字体；品牌字形和计数少量使用衬线；正文以可读性为先 |
| 图标 | Lucide 线性图标只标明操作或类别；不使用星芒代表“智能” |

移除轨道、漂浮点、叶片装饰、安排妥当标签和反复出现的陪伴口号。首页显示真实事项和提醒数量。登录页使用简单版面与三项功能索引；品牌字标保留为 `n.` 与 Nemi。

应用目录使用列表和能力详情，包含搜索、生活 / 办公筛选、平台状态、可执行操作和使用范围。品牌色只用于小图标，主操作仍遵守统一设计。未实现的条目以“规划中”展示，不提供无效授权按钮。

## 交互

- 创建事项、保存时间和外部群发送分别确认；发送预览明确显示目标群与正文。
- 日历下载或地图跳转由用户点击触发，不在打开页面时访问外部平台。
- 手机侧栏可关闭，账户入口在短屏保留；操作区可滚动，不出现页面横向溢出。
- 应用在窄屏先展示当前操作，再列出目录；选择应用后将视口带到对应详情。
- 控件保留键盘焦点、表单标签、错误提示和禁用状态；遵守 reduced-motion。
- 配置、接受、拒绝和不确定回执使用准确文字；不确定回执不用成功勾号。

“去除 AI 味”涉及视觉和文案，不隐藏事实：演示生成仍标明演示；真实模型内容仍需核对。站内提醒、单次日历导出、待配置群机器人与规划中的账号读取能力仍各自说明限制。
