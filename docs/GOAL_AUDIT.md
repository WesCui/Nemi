# 完整项目目标跟踪

日期：2026-10-05 · 代码 v0.12。原目标是完整实现对标 dots / Meta Muse 的国内个人 Agent；一个版本通过测试不代表完整目标完成。

| 目标 | 已有证据 | 仍需完成 |
| --- | --- | --- |
| 自然语言通用助手 | 真实 BYOK 对话、计划、工具循环、摘要与停止；已有事项/清单/截止时间/状态/提醒和偏好的对话内提案与确认 | 跨轮长期目标、完成条件、主动唤醒、委派；事项硬删除及隐私历史删除 |
| 内部连接和操作应用 | 共享能力目录、持续对话入口、七种连接卡片及修改/停用确认、飞书 docx、群消息、日历成果、博查/高德/QQ与网易IMAP执行协议 | OAuth、在线日历/云盘、事件入口、国内交易及真实账号验收 |
| 资料与成果 | 附件、公开网页、精确统计、内部预览和 Excel/文字下载 | OCR、图片、PDF/Word 生成、复杂计算、删除管理 |
| 云端电脑与浏览器 | 服务端匿名页面渲染、网络约束、正文资料；本机JS/阻断测试 | 隔离浏览器、会话凭据、用户接管、页面操作及证据 |
| 操作审批 | 前后快照、版本保护；消息目标固定，未知回执不重发；用户允许原模型后，审批结束持久自动续办 | 通用权限策略及购买/支付/历史删除的具体授权；真实模型和平台全链路验收 |
| 记忆 | 确认偏好、持久摘要、完整聊天与事项资料 | 可管理的语义检索、来源冲突处理、质量评估 |
| 持续工作 | Temporal、Outbox、费用账本、周期站内提醒；有界审批等待和 Worker 重启后续办 | 长期研究、完成验证、变化通知与重规划；当前续办最多八次且根任务七天 |
| 大众移动入口 | 响应式 Web、手机对话及审批测试 | 微信小程序、语音、手机推送、跨渠道身份 |
| 国内模型 | 五家供应商、个人 Key/型号/单价、任务配置不可变 | 各家真实工具兼容性及账号验收、恢复与指引 |
| 公开部署 | 邀请口令单个人空间、持久加密、测试隔离 | 多用户身份、生产 Temporal、硬资源隔离、观测、备份及容量验收 |

截至 v0.11，本机有一个通过检查的用户模型和两轮成功真实对话；其中只读能力问询经过两次模型请求，调用 list_applications 并完成答复。v0.12 已追加真实个人模型的公开网页读取、资料保存及答复验收；网络失败和早期次数耗尽记录也保留。文件、数据修改、连接管理和续办完整工具链尚未全面用真实模型验收；实群、飞书、搜索/地图/邮箱账号和云端桶暂无实账号验收记录。协议测试、真实本地 Temporal 和本地 UI 只能证明相应合同，不能代替平台授权或真实资源联调。凭据通过 Nemi 专用字段填写，不提交 Git、不发送到开发聊天。


v0.12 增加六项联网工具，不改变完整目标仍未完成的判断。实时搜索/地图和邮箱需要专用真实凭据；交易、个人微信和在线文档账号未接入。详见[实际范围](./ONLINE_TOOLS.md)。
