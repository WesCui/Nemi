# 完整项目目标跟踪

日期：2026-10-05 · 代码 v0.9。原目标是完整实现对标 dots / Meta Muse 的国内个人 Agent；一个版本通过测试不代表完整目标完成。

| 目标 | 已有证据 | 仍需完成 |
| --- | --- | --- |
| 自然语言通用助手 | 真实 BYOK 对话、计划、工具循环、摘要与停止；已有事项/清单/截止时间/状态/提醒和偏好的对话内提案与确认 | 跨轮长期目标、完成条件、主动唤醒、委派；事项硬删除及隐私历史删除 |
| 内部连接和操作应用 | 四种连接卡片、飞书 docx、三平台群提案/确认/回执 | OAuth、日历/邮件/云盘、事件入口、国内生活服务和真实账号验收 |
| 资料与成果 | 附件、公开网页、精确统计、内部预览和 Excel/文字下载 | OCR、图片、PDF/Word 生成、复杂计算、删除管理 |

| 公开部署 | 邀请口令单个人空间、持久加密、测试隔离 | 多用户身份、生产 Temporal、硬资源隔离、观测、备份及容量验收 |

本机已有一个通过检查的用户模型和一轮成功对话；新增文件和数据修改工具链尚未用用户 Key 额外付费验收，实群、飞书和云端桶暂无验收记录。协议测试和本地 UI 只能证明相应合同，不能代替真实模型、实群、飞书授权或云端桶联调。继续推进不依赖凭据的能力；凭据通过 Nemi 专用字段填写，不提交 Git、不发送到开发聊天。
