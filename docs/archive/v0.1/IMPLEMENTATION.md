## 本地验证证据

- Go 单元测试：时间确认、提醒静默边界、结构化模型输出及费用计算。
- 国内模型离线请求合同：固定 HTTPS 端点、单次请求、2048 输出 Token 上限、JSON 内容解析。**没有真实模型联网测试**。
- PostgreSQL 17.10 集成测试：16 个并发请求去重、同键不同内容冲突、跨空间访问拒绝、提醒 revision 失效与交付去重、清单版本保护、未知费用预留、准入重试去重与每日预算上限。
- Temporal CLI 1.9.1 / Server 1.32.0 实际联调：持久提醒工作流、Worker 替换恢复、重复引擎派发与持久结果；使用独立测试空间和队列。
- Next.js 16.3.8 / React 19.3.0：TypeScript 与生产构建通过。
- Playwright / Chrome：3 项测试通过，覆盖桌面完整事项流程、移动端无横向溢出与连接器状态、北京时间跨 UTC 日期的免打扰预览。清单下载及刷新后持久状态经过验收。
- `go vet` 通过；GitHub CI 已配置，本地通过不代表远程 CI 已完成。

浏览器首轮暴露的标题换行匹配问题已修正；清单勾选的异步显示问题改为立即反馈，保存失败恢复并提示。手机截图按初始移动视口加载，避免拍摄桌面侧栏切换动画的中间帧。

## 运行与恢复约束

当前电脑 3000 端口属于 Windows TCP 保留范围，因此本地预览使用 **http://localhost:3100**，`.env` 的 `APP_ORIGIN` 已对应调整。默认仓库示例仍为 3000；其他电脑可按自身环境选择端口。

本机通过 Git Bash、原生 PostgreSQL 与官方 Temporal CLI 验证，数据保留在被 Git 忽略的 `data`；密钥、口令与缓存不提交。运行步骤见 [开发指南](../../DEVELOPMENT.md)。`AGENTS.md` 已约定后续构建、测试与 Git 操作使用 Bash，`scripts/env.sh` 按字面值加载配置，不执行环境文件中的文本。

网页关闭不停止已保存任务。提醒到期不调用模型，Worker 缺席后由 Temporal 保留待执行工作；提醒实际记录前检查最新 enabled / revision。记录出现不等于用户已阅读。

真实模型调用中断与确定性提醒恢复是不同合同：无可靠下游请求幂等 / 回执时，付费模型请求的结果可能未知。本版不会自动重发该请求，Run 终止并保留未知费用；重试由用户创建新 Run，仍受每日总预算约束。
