# Nemi v0.12 实施状态

日期：2026-10-05。[v0.4 验收存档](./archive/v0.4/IMPLEMENTATION.md)保留前版模型与应用配置的范围。

## 本轮交付

- 应用目录改为对话入口，共享十五项能力合同，保留历史、模型、附件与草稿；支持能力查询、固定版本的连接修改与停用提案，以及真实日历成果。新增搜索、高德、邮箱及匿名网页浏览，账号或交易未接入的平台明确显示尚未接入。详见[对话应用操作](./CONVERSATIONAL_APPS.md)。

- 复杂任务在操作提案后调用 await_actions，保存原目标和具体下一步；用户允许原模型继续，逐项确认或取消后，后台核对结果并创建唯一后续轮次。关闭页面、Worker 重启和重复信号不丢失等待、不重放父轮次模型请求，详见[确认后继续](./CONTINUATION.md)。
- 新消息取消旧等待，停止后续执行可阻止已入队子任务；模型撤销、到期或原轮次失败会停止续办。已确认操作仍有效，未知群消息回执不重发。等待不调用模型，各次新等待需明确允许，并受24小时等待、七天根任务和八次后续轮次限制。
- 用户通过对话修改已有事项标题、资料、清单、截止时间和状态，调整 / 停用站内提醒，保存 / 修改 / 移除偏好。Agent 读取真实 ID 与版本后准备前后对照卡片，用户确认后才保存；详见[对话修改](./AGENT_ACTIONS.md)。
- 提案固定当前事项与提醒的双版本或偏好版本，旧提案不能覆盖新内容。12个并发确认只执行一次，日期在确认时再次检查；归档停用提醒、保留历史并可恢复，偏好移除不删除聊天原文。

- 删除产品的确定性演示生成器及相关入口。所有模型任务需要用户配置的真实 Key 与型号，或运维配置的真实服务端模型。无模型返回 HTTP 412，不创建运行或替代答案。
- 首页是个人 Agent 对话入口，支持多轮上下文、新对话、历史切换、刷新恢复、模型选择、Enter 发送与输入法保护。普通对话不自动创建事项；生活、工作、学习、研究都可从同一入口开始。
- 直接复用 CloudWeGo Eino v0.9.21 ReAct 编排，模型选择工具，执行结果回传给模型继续处理。每轮最多 6 次模型请求、12 次工具调用、10 分钟执行时间；工具顺序执行，单次返回受大小限制。
- 原有十项工具：北京时间、事项列表、指定事项资料、已保存偏好、应用连接状态、用户明确提供的飞书 docx 文档读取、事项 / 站内提醒提案、任务计划、内部应用连接引导、群消息提案。工作空间来自认证任务，模型不能选择其他用户、访问凭据或自行确认操作。
- 对话展示执行过程与完整提案卡片。事项 / 提醒待用户点击确认后才写入实际数据；确认与 Outbox 同事务提交，重复确认不重复创建，取消提案和已过期日期不会执行。下一轮注入提案实时状态，区分 pending / approved / declined。
- 每次模型请求先提交唯一步骤 claim、预留费用、检查模型撤销，再调用固定供应商接口；结算每步用量，未知结果保留预算，不自动重发。数据库结算失败和 Worker 中断不擦除已知费用。
- 长对话使用 Eino 摘要组件，合并旧摘要与全部待整理成功历史，保存覆盖位置并保留近期原文；完整聊天记录仍在数据库中。摘要调用计入所选模型的费用，不能用固定生成替代。
- 持久任务计划、规范参数重复工具保护、停止当前执行；停止后的 Worker 不能新增提案、计划或摘要，迟到结果只允许结算费用。
- 在对话内保存飞书文档与三平台群机器人配置，点击继续原任务。群消息由 Agent 准备，用户确认接收群与正文后真实投递；配置变更阻止旧提案，刷新保留回执，未知结果不重发。

原有五个国内模型服务商、AES-256-GCM 凭据存储、飞书文档导入、三个群机器人、事项版本、已确认偏好、站内周期提醒继续保留。飞书使用官方 Go SDK 与已配置且授权的自建应用；目前只有 docx 正文，未接入 OAuth、wiki、附件或写回。应用目录现在提供内部对话入口，移除高德跳转工作流；ICS 在对话生成真实文件，其他待接入平台不能通过 Agent 自动操作。

v0.8 新增六项工具和对话内资料流程：PDF/DOCX/XLSX/CSV/文字上传、按聊天授权读取、公开 HTTPS 网页正文、精确表格统计、文字/Excel 成果持久化与内部预览下载。合计十六项工具，真实模型继续选择及使用工具，不引入演示生成器。具体范围与限制见 [FILES](./FILES.md)。

v0.9 新增四项数据读取 / 修改提案工具，合计二十项。事项和偏好支持内容搜索，清单分页读取；指定条目修改由服务端在全量清单上合并，模型不能提交截断后的整份清单覆盖其他项。

v0.10 新增 await_actions，直接复用 Eino ReAct 的 SetReturnDirectly 暂停循环；下一步由所选真实模型规划，产品没有固定报告生成回退。v0.11 增加应用能力查询、停用连接提案和日历导出，合计二十四项工具。

## 执行与数据合同

conversations / chat_turns 独立保存对话，runs 复用 Outbox / Temporal；schema v8 的 context_summary、summary_through 与 task_plan 继续保留；v9 新增 workspace_files 和 chat_run_files，文件原文及解析结果在加密对象中。会话快照上限 40000 字节，超过四轮或 10000 字节时整理较早原文；已有极长历史超过单次整理上限时明确拒绝并建议新开对话，不悄悄裁剪。本轮含工具定义与结果的请求 JSON 上限 48000 字节。每空间 100 段对话、每段 200 轮、最多 10 个等待处理的对话，每段至多一个活跃轮次。具体合同见 [harness](./HARNESS.md)。

schema v10 扩展事项 ARCHIVED 状态，不删除既有用户数据。数据修改和审批状态同事务提交，归档与完成同时写入提醒取消 Outbox，恢复不重启提醒。

schema v11 新增 agent_continuations、运行链根 / 深度 / 取消标志和后台事件来源。授权、操作决策、运行结束和回执各与信号 Outbox 同事务提交；ContinuationWorkflow 只重试数据库操作并保存 timer / signal，后续模型调用仍由既有 RunWorkflow 处理。运行与续办行锁先于业务事件序号锁，首次等待注册与审批也序列化，防止确认和取消互锁。

个人配置不可变，型号、费用单价、提示合同 agent-v7 / plan-v2 与配置 ID 固定到新运行；历史运行保留原合同。默认切换不改变已入队任务及旧目标的续办；撤销阻止后续步骤，在途调用可能完成。API / Worker 共享加密主密钥，凭据不回显、不进 Temporal 参数、业务事件或 Git。模型收到本段历史及本次工具读取的资料，界面明确说明这点。

单轮预算 1 元、每空间每日 3 元（按获准执行的北京日归属）、全局 5 个 / 每空间 2 个活跃运行。多步调用按剩余预留 + 已结算费用占用预算；追加预留使用 admission 同一数据库锁。服务商账单为实际费用依据，配置单价用于本地预算。

## v0.12 联网能力

已新增 search_web / browse_web / search_places / plan_route / list_mail / read_mail，合计30项工具，agent-v7 / plan-v2，schema维持v11。博查搜索、高德地点与步行/驾车路线、QQ/Foxmail/163/126只读IMAP具有真实执行 Adapter、内部连接同意与加密表单；成功读取才标记验证，停用和换配置仍有版本保护。匿名服务端浏览器用Playwright渲染JS公开页面，经受控公网GET/HEAD网关并保存正文成果，未实现登录接管和交易。详细合同见[联网工具](./ONLINE_TOOLS.md)。

后端全量 Go 测试使用专用 nemi_test 与隔离 Temporal 队列通过，go vet 通过。本机真实浏览器验证 JS 渲染且 POST 与内网请求未到达网络；邮箱 wire 测试验证 EXAMINE、BODY.PEEK 和版本锁定。浏览器页面失败不会被分类成已知的浏览器未安装。博查、高德和邮箱无真实凭据时不能执行实际账号查询，不以协议替身称为账号联调。容器镜像定义可选 Dockerfile.browser，本机未执行容器构建；Compose 配置检查通过。

真实个人模型已成功调用 browse_web 读取公开页面，将 917 字符正文加密保存为本对话的浏览器资料.txt，经 read_file 核对后完成 522 字符中文答复，共三次模型请求，没有连接账号、发送消息或创建事项。实际登录 UI 验证十五项目录、内部对话入口、资料预览与下载，原始失败记录仍保留。五个 Go 发布文件与最终构建一致，本地 API、两个 Worker、Relay 和 localhost:3100 已更新，原 PostgreSQL、Temporal、用户数据和经过检查的模型配置保留。

早期 Go 文档站读取已成功保存约一万一千字符，但连续分页耗尽六次请求而没有答复。已将第六次请求专用于收尾，关闭工具并要求说明未读范围；真实 ReAct 回归测试通过。随后一次网络访问失败，模型如实返回没有取得正文；该轮状态成功只代表答复已生成，不代表网页任务完成。两条原始验收记录及已产生资料均保留，不修改历史来掩盖失败。

聊天通过 react-markdown 和 remark-gfm 展示真实答复的标题、来源、列表、表格和代码；原始 HTML 不执行，外部图片不加载，链接限制到 HTTP/HTTPS 或页内锚点。25 项完整隔离端到端验收通过（2.3 分钟），包含三类服务连接与同意、凭据不进入对话、危险链接/HTML/追踪图片阻断、手机布局，以及原有聊天、审批续办、资料统计和连接管理。Next.js 最终生产构建与 TypeScript 检查通过，localhost:3100 已切换最终产物；真实回复的标题和强调、源文件下载、手机侧栏收起与预览窗口已在实际登录页面核对。
