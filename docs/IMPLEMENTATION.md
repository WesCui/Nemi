## 使用与恢复

本机预览 **http://localhost:3100**，API 为 loopback 8080。Windows 的 3000 端口保留范围问题继续按开发指南处理；仓库默认示例为 3000。命令、测试和 Git 使用已安装的 Git Bash；不要用 PATH 上可能指向 WSL 的 bash。

`scripts/env.sh` 字面读取 .env，可选连接器只从服务端读取。凭证、邀请口令、会话、数据、生成缓存和测试截图不提交。三平台接入配置、官方来源与权限边界见 [国内应用接入](./INTEGRATIONS.md)，视觉规则见 [界面设计](./DESIGN.md)，开源许可证见 [开源复用](./OPEN_SOURCE.md)。

schema v4 新增发送账本，不删除旧表或用户内容。已有长期提醒仍采用原 Workflow，默认队列名称不变；测试服务可以配置独立运行 / 提醒队列。部署队列变更必须同步 Worker 和 Relay，不应让生产任务落到测试队列。

外部群消息通过 API 同步发出，网络调用前持久化 claim。崩溃、超时、断连或无法保存回执时，查询显示 UNKNOWN，自动恢复不再次调用平台。Webhook 重配不自动验证或发送测试消息。
