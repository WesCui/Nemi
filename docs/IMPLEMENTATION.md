# Nemi v0.4 实施状态

日期：2026-10-04。页面取消私人开发版标记，推进国内个人产品功能。[v0.3 验收存档](./archive/v0.3/IMPLEMENTATION.md)保留此前应用协作合同。本文区分代码交付、协议测试与真实账号验收。

## 本轮交付

| 功能 | 实现 | 实际范围 |
| --- | --- | --- |
| 首页模型配置 | 五个国内服务商、个人密钥保存、默认与逐任务选择、删除、确认后的后台连接检查 | 固定官方 API；具体型号需账户权限。检查调用有费用，保存不调用 |
| 任务模型绑定 | 不可变配置 ID、型号、价格和提示词版本快照；按选定模型预算与调用 | 切换默认不影响已提交任务；删除阻止尚未 CALLING 的任务；在途调用可能继续 |
| 凭据存储 | 标准库 AES-256-GCM，随机 nonce、空间与用途 AAD；本地持久主密钥或部署密钥 | 本地文件需要与数据库分别保护及备份；尚未采用生产 KMS、轮换与多用户身份 |
| 群消息 | 飞书 / 企微 / 钉钉页面设置、目标版本检查、确认发送、接收回执与成功验证时间 | 群机器人仅用于发送文字，不提供读取群聊、个人微信或日历的权限 |
| 飞书文档 | 官方 SDK v3.12.0，显式应用令牌、docx 纯文本读取、事项导入、来源链接 | 飞书自建应用，需发布、读取权限和文档授权；不是用户 OAuth，也不支持 Wiki、表格、附件或编辑 |
| 界面 | 纸白 / 炭黑 / 深绿；首页模型弹窗、逐任务选择、应用配置与联调操作 | 演示与未验证状态保留，不把保存成功当作接入成功 |

保留原有清单、修改资料、偏好、周期提醒、Outbox、SSE 和费用合同。单次任务仍是一次文本模型调用，未实现通用 Agent Tool Loop。

## 安全与执行合同

- API 返回模型与应用的非敏感元数据；原始凭据不存入命令响应或业务事件。命令表只存请求哈希与脱敏结果。
- 主密钥由 API / Worker 共享；本地通过完整临时文件 + 原子 hard link 发布，避免并发初始化生成不同密钥。Compose 使用同一命名卷，目录归运行用户所有。
- 浏览器验收使用独立身份、工作空间、主密钥与随机 Temporal 队列；Outbox 消费范围限定到本次工作空间。后端和浏览器测试串行运行，避免共用测试库的全局配额与身份互相干扰。
- 个人配置不可变。换密钥用新配置，再移除旧配置；撤销清空该行密文并取消其默认选择。
- 模型在 RESERVED → CALLING 的事务中再次验证配置仍有效，失败在提交前回滚并释放未使用预算。已提交或结果不确定不自动重发。
- 费用按用户填写的每百万 Token 单价预估，单次上限 1 元、每日 3 元；实际账单以服务商为准。缓存折扣与动态价格尚未自动同步。
- 群消息提交携带所确认的配置 revision；改接收群后需刷新再确认。发送前 PG claim，网络结果不明不重发，平台接受不等于已阅读。
- 飞书 SDK 禁用持久令牌缓存、输出静默日志，HTTP 限定官方地址、禁止跳转、响应最多 1 MiB。纯文本导入上限 12000 字节；读取期间配置变化会阻止导入提交。
- 导入只读取指定文档、保存当前文字与来源，不自动修改外部文档，不自动调用模型。

## 验证证据

- Go 全量单元与 PG 集成测试、go vet、四个服务构建。
- 专用 nemi_test 与私有随机 Temporal 队列：真实持久引擎执行个人模型任务，外部模型 HTTP 使用协议替身，验证选定账号、费用结算与默认切换后的稳定绑定。
- 五家模型 HTTP 合同、飞书 SDK 认证和文档合同、签名、来源限制、撤销前提交保护、并发主密钥初始化、API 不回显密钥和请求去重。
- Chrome 浏览器九项流程全部通过（49.6 秒）：既有生活事项、提醒、偏好、应用操作，以及新增个人模型持久设置、手机弹窗、机器人配置与无自动发送。
- Next.js 生产构建与类型检查。

以上不等于真实服务商 / 飞书租户 / 实群已经联调。尚未得到有效账号凭据，不能伪造这些验收；用户可在已完成的本地配置界面填写后验证。Docker 镜像与 Compose 服务尚未完成本机容器验收。
