# 对话资料与成果

日期：2026-10-05 · v0.8 · schema v9 · 提示合同 agent-v3。

用户在首页对话中附加资料，直接输入“统计这份账单并生成 Excel 汇总”或“结合网页和附件写一份报告”。Agent 调用所选真实模型与工具，文件留在同一对话，可内部预览、下载和刷新恢复。上传本身不调用模型；发送任务必须有有效模型配置。

## 实际范围

支持 UTF-8 TXT、Markdown、JSON，CSV/XLSX 表格，DOCX 主体正文及含可提取文字的 PDF。公开 HTTPS 网页读取保留实际最终 URL 和获取时间，没有搜索、登录浏览器、脚本操作或付费墙绕过。扫描 PDF/OCR、图片理解、DOCX/PDF 成果生成、任意 Python 计算和文件删除尚未交付。

表格工具读取完整数据，纯十进制使用精确有理数累加，返回总和、平均、最小、最大和跳过行数，支持按列分组；显示至 8 位小数，不自动换算币种/单位。成果支持 TXT、Markdown、JSON、CSV 和 XLSX；Excel 写成纯文本单元格，不执行公式，CSV 公式前缀中和。只有文件持久化成功才显示成果卡片。

## 大小和权限

每条消息最多 4 个附件，每个 5 MiB；每空间累计 200 个文件或 100 MiB，目前不回收配额。解析内容最多 256 KiB；PDF 最多 50 页；Office ZIP 最多 500 条目、总解压 32 MiB、单条目 10 MiB；表格最多 25 张、单表 5000 行/100 列，总计 20000 单元格。超限明确拒绝，不悄悄裁剪。

正文工具按 Unicode 字符分页，每次最多 2000 字符；表格最多 20 行，可指定列，返回下一位置和总量。预览明确显示前 12000 字符或每表前 100 行，上传下载保留完整原始文件；网页文件下载为提取的正文。生成成果单次内容最多 5000 UTF-8 字节，仍受单轮模型和工具预算约束。

新增 `list_files`、`read_file`、`read_table`、`analyze_table`、`read_webpage`、`create_artifact`。`workspace_files` 保存元数据，`chat_run_files` 绑定输入和输出；附件、聊天轮次与 Outbox 同事务提交。Agent 只能读本聊天截至当前轮次明确附加的文件及已生成成果，不能读其他聊天/空间或未来轮次。文件及网页是非可信资料，不授予权限；正文在工具实际调用时发送给所选模型。

## 存储与执行

原始字节和解析结果以同一个 AES-256-GCM 信封保存，AAD 绑定空间与文件 ID；PG 不存正文。默认 `data/files/<空间哈希>/<文件ID>`，对象路径不使用用户文件名。下载须认证，由 API 解密返回，不产生公开 URL。文件名、大小、时间和来源 URL 是所有者可见元数据。

上传按请求标识去重，成果按运行与规范参数去重。持久写入前锁定活跃运行和空间配额，停止后不新增成果。对象写入后 DB 提交结果不确定时保留对象，避免删除可能已引用的数据；未引用对象核对清理、用户删除和配额回收待后续实现。

相邻 `file-parser` 二进制负责解析 PDF/Office，最多两个并发、10 秒超时、清除主服务凭据环境、单核及 128 MiB Go 软内存目标；还有 ZIP/页数/输出限制。**这不是操作系统级沙箱或硬内存隔离**，生产上传还需容器/进程硬资源限制及恶意样本验证。宏拒绝，嵌入程序、外部链接和公式不执行。

网页仅允许公开 HTTPS 默认端口，不带账号或常见密钥查询参数，不携带 Cookie/Authorization，不用环境代理。每次连接解析 DNS，所有返回地址须公开，再直接连接已验证 IP，TLS 使用原始域名；阻止私网、环回、链路本地、CGNAT、保留与 IPv6 转换地址。本机 VPN 的 198.18.0.0/15 Fake DNS 情况下，通过固定 223.5.5.5 地址访问 [阿里公共 DNS](https://alidns.com/) 的 TLS DoH 服务，只发送目标域名；响应中的实际 IP 仍须全部通过公网校验，私网或混合结果不使用此回退。最多三次跳转并重新检查，响应正文最多 1 MiB、提取正文最多 256 KiB。动态网页可能无法读取。

## S3 配置与验证

默认加密本地对象，Compose 共用 credential-data 卷。S3 兼容服务使用 `.env` 中的 `FILES_S3_ENDPOINT`（host:port）、`FILES_S3_BUCKET`、`FILES_S3_ACCESS_KEY`、`FILES_S3_SECRET_KEY`、`FILES_S3_REGION`、`FILES_S3_SECURE`。预先创建私有桶与最小读写凭据；MinIO SDK v7.3.0 不自动建桶或回退本地。使用 TLS；关闭 TLS 只适合可信本地测试。切换后端需要迁移旧对象及元数据，目前不能同时读取两个后端。备份须包括产品库、对象及 Vault 主密钥。

Go 测试覆盖格式、ZIP 限制、文本 PDF、原始表格、精确小数、公式安全导出、跨聊天/空间权限、上传去重和停止后拒绝写入。S3 使用实际 SDK 与受控协议服务验证加密对象往返，真实云端桶尚未验收。浏览器使用独立 nemi_test/Temporal 队列与仅编译进测试程序的模型替身；不等同于真实模型账号联调。
