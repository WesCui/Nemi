# 国内应用接入与场景

日期：2026-10-04。对应代码 v0.3 私有开发切片。优先级依据“个人用户、生活助理优先”的产品判断，不是市场份额排名。目录中的“规划中”条目只介绍候选场景，不能视为已连接账号。

## 当前可用范围

| 应用 | 典型用途 | 代码状态 | 授权与限制 |
| --- | --- | --- | --- |
| 高德地图 | 查找目的地、办事地点、餐厅 | 已实现官方 URI 搜索跳转 | 点击后向高德传递关键词与可选城市；不读取定位、历史或订单 |
| 系统日历 | 把下次提醒 / 截止时间放入日历 | 已实现 .ics 下载 | 单次 15 分钟事件，不自动同步；需自行导入，日历按其时区显示 |
| 飞书 | 发送行李清单、会议准备和材料清单 | 已实现文字群机器人 Adapter | 管理员设置 Webhook、群名；启用签名时设置 Secret；每次用户预览并确认 |
| 企业微信 | 材料交接、工作安排 | 已实现文字群机器人 Adapter | 管理员设置群机器人 Webhook、群名；群内成员可见；不读取个人微信 |
| 钉钉 | 将准备清单交给同行 / 同事 | 已实现加签文字群机器人 Adapter | 必须设置 Webhook、Secret、群名；逐次确认发送 |
| 微信 | 小程序提交事项、订阅提醒 | 规划中 | 需小程序账号、模板资格和用户订阅；不能当作个人聊天读取接口 |
| QQ / 163 邮箱 | 行程确认、缴费、报名材料 | 规划中 | 后续分别核验授权协议与读取范围；不接受邮箱登录密码；当前手动粘贴 |
| 腾讯文档 | 从指定文档整理会议行动项或材料 | 规划中 | 开放平台应用与文档授权待核验；仅贴网址不获得访问权 |
| WPS | 选定文档和表格的准备事项 | 规划中 | 官方提供 OAuth 和权限范围；第三方应用资格、具体文件权限需申请核验 |
| 铁路 12306 | 证件检查、出发提醒、车次资料整理 | 规划中 | 当前按用户提供资料整理；没有个人订单读取、购票或退改能力 |
| 美团 / 大众点评 | 聚会、餐厅预约和周末出行 | 规划中 | 当前按选定资料整理；未验证个人订单接口，不代预约或付款 |
| 淘宝 / 京东 | 购物清单、收货与售后期限提醒 | 规划中 | 当前按用户提供购买资料整理；尚未核验可用于个人订单的官方授权 |

群机器人已经完成离线协议验证，**没有真实群账号联调**。配置状态只证明端点格式、群名和必需字段有效，不证明凭证有效、机器人安全策略匹配或成员身份正确。请在本地确认目标群，勿在聊天或 Git 中提供 Webhook。

## 三条首批闭环

1. **周末出行**：输入同行人数、预算和安排 → 确认清单 → 在高德查目的地 → 导出出发前提醒。群内协调时，可选把清单预览后发送到已配置的群。
2. **报名与办事材料**：粘贴本人选择的邮件 / 文档文字 → 整理待准备材料 → 确认截止日期 → 日历导出。邮箱和文档自动读取留待授权接口接入。
3. **生活与工作交接**：更新事项资料 → 生成最新清单 → 选择飞书 / 企微 / 钉钉接收群 → 编辑正文 → 确认群内可见 → 检查平台回执。提醒仍是站内记录，不会自动进入外部群。

## 配置和使用

在本地 `.env` 中填写 `.env.example` 的 `CONNECTOR_<PLATFORM>_WEBHOOK`、`CONNECTOR_<PLATFORM>_GROUP_NAME`，以及需要的 `CONNECTOR_<PLATFORM>_SECRET`，随后重启 API。平台名为 `FEISHU`、`WECOM`、`DINGTALK`。Webhook 自身也是凭证，应与模型 Key 一样保护。

飞书可启用签名验证，启用后必须填写 Secret；本版钉钉要求加签。若还启用了关键词或 IP 安全规则，应在平台侧按实际部署设置，并确保正文符合规则。Nemi 不自动加入关键词或 @ 群成员，以免改变用户确认的正文。

应用页面会显示“待配置”“配置待检查”或“已配置 · 未验证”，不显示虚假的“已连接”。填写接收群名用于发送前核对；服务端无法从 Webhook 确认真实群名，管理员须维护准确。更换接收群后应同时更新群名。

发送正文最多 1800 UTF-8 字节。可从现有事项填写标题和清单，也可自行编写；不会默默带上资料原文或偏好正文。预览确认之后才发生外部调用。

## 接口与发送合同

- `GET /api/v1/connections`：只返回平台、群名和配置状态，所有路由要求登录。
- `POST /api/v1/connections/{id}/messages`：正文为 `text`、`confirmed`，并携带 `Idempotency-Key`；用户不能提供 Webhook、目标账号或空间身份。
- `GET /api/v1/matters/{id}/calendar`：按当前空间读取一个活跃事项，优先使用仍有效的下次提醒时间，否则使用截止时间。没有时间则拒绝导出，不猜测日期。

发送先在 PG 提交持久 claim，再调用平台一次。相同标识、平台和正文返回原回执；相同标识改变正文或平台则拒绝。重启后不会重新发送 SENDING 请求，重读时按 UNKNOWN 展示。无网络回执、非 200 或缺失 / 无效的结果码都视为 UNKNOWN；只有明确成功码才视为 DELIVERED。DELIVERED 表示平台接受，不表示成员阅读。

UNKNOWN 不会自动重试；用户先在接收群核对。明确业务拒绝显示 REJECTED。网络调用后即使浏览器断开，也尝试持久化回执；持久化失败保留不确定结果。每空间最多每分钟 10 次、滚动 24 小时 100 次新发送，重读原标识不重复占用额度。

凭证仅从服务端配置读取。只接受三个官方 HTTPS 域名和指定路径，不允许重定向、非默认端口、附加查询参数或客户端自定义 URL。错误不回传上游原文 / URL，避免 Webhook token 被输出。DB 发送账本只保存请求哈希与状态，不保存正文或 Webhook。没有通过 Temporal 自动重试外部消息。

日历序列化复用 `arran4/golang-ical v0.3.7`（Apache-2.0），避免手写转义和折行。只导出一个事件，不导出整段周期规则；免打扰调整后的下次时间来自提醒事实。源资料、偏好和完整清单不进入 .ics。

## 调研来源与证据边界

实际接入协议参考：[高德 URI 搜索](https://lbs.amap.com/api/uri-api/guide/search/search)、[飞书自定义机器人](https://open.feishu.cn/document/client-docs/bot-v3/add-custom-bot)、[钉钉机器人安全设置](https://open.dingtalk.com/document/group/customize-robot-security-settings)、[腾讯云官方三平台 Webhook 说明](https://cloud.tencent.com/document/product/1813/130774)。飞书和钉钉的动态官方页面通过浏览器读取，签名实现分别核对秒 / 毫秒时间戳与 HMAC 输入；测试使用独立固定向量及模拟 HTTP，不发送真实消息。

后续权限参考：[微信订阅消息官方腾讯云实践](https://cloud.tencent.com/document/product/1301/103770)、[WPS 用户 OAuth 流程](https://open.wps.cn/documents/app-integration-dev/wps365/server/certification-authorization/user-authorization/flow)、[WPS 开发者资格](https://open.wps.cn/documents/app-integration-dev/guide/developer)。微信一次性订阅需要用户触发并允许；不能承诺任意无限推送。WPS 第三方个人应用也需要服务商认证与允许的权限范围。

[腾讯文档生态](https://docs.qq.com/open/)、[京东开放平台](https://open.jd.com/)是后续核验入口；此轮未确认个人账号 API 范围。邮箱、美团、淘宝、12306 的个人内容接口资格也未完成核验，表中的场景为设计判断。没有使用爬虫、私有登录协议或浏览器 Cookie 模拟平台授权。
